Configuration — start points (form + YAML, saved in this browser)

Private start points live only in this browser (localStorage), never in the repo. Edit the list: add/remove, drag ⠿ to reorder (order is kept), uncheck to keep a point out of planning; type lon, lat (a pasted lat, lon is auto-detected) or pick 📍 on the map. The YAML below mirrors the form and auto-saves; hand-edited YAML applies with Apply YAML. Format: top-level pois: list of label/lon/lat (+ optional enabled: false); optional squares_uid prefills the uid; a legacy name: mapping still loads.
